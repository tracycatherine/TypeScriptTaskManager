# TypeScript Task Manager

## Overview

This project was created to explore and learn **TypeScript** by building a practical, small-scale application. The software is a **Task Manager** that allows users to:

- Add tasks  
- Mark tasks as completed  
- Delete tasks  
- View the current list of tasks  

The purpose of this project was to practice **TypeScript syntax, strict typing, arrays, functions, and code organization** while creating a functional application.  

The project helped me understand how TypeScript enforces **type safety** and how it differs from plain JavaScript, as well as how to structure a small Node.js application using TypeScript.  

[Software Demo Video](https://www.youtube.com/watch?v=ef479ImSDSA)

---

## Development Environment

- **Visual Studio Code** – code editor used for development  
- **Node.js** – runtime environment for executing the TypeScript code  
- **TypeScript** – language used for building the project  
- **tsconfig.json** – configured for strict type checking, source maps, and declaration generation  

No external libraries were used; the focus was on learning **core TypeScript features**.

---

## Features

- **Add Tasks** – Users can add tasks with a name  
- **Complete Tasks** – Mark tasks as completed  
- **Delete Tasks** – Remove tasks from the list  
- **View Task List** – Display all tasks with their completion status
