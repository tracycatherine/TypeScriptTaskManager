# TypeScript Task Manager

## Description
This project demonstrates the TypeScript programming language by building a simple task management system.

## Purpose
The purpose of this software is to demonstrate how TypeScript improves JavaScript development by introducing static typing, interfaces, and classes.

## Development Environment
- Visual Studio Code
- Node.js
- TypeScript

## Programming Language
TypeScript
